# MAJÖR Gayrimenkul

Hatay İskenderun'da faaliyet gösteren MAJÖR Gayrimenkul'ün tanıtım sitesi.

Sade bir yapı: HTML, CSS ve az miktarda JavaScript. Derleme adımı yok,
kurulum gerekmez — `index.html` dosyasını tarayıcıda açmak yeterli.

## Dosyalar

- `index.html` — sayfanın tamamı ve bütün metinler
- `styles.css` — renkler, yazı tipleri, düzen
- `script.js` — mobil menü ve kaydırma efektleri
- `favicon.svg` — tarayıcı sekmesi simgesi

## Güncelleme

Metin, iletişim bilgileri ve renkleri değiştirmek için
[NASIL-GUNCELLERIM.md](NASIL-GUNCELLERIM.md) dosyasına bakın.

## Yayın

Vercel üzerinde barındırılıyor. `main` dalına gönderilen her değişiklik
otomatik olarak yayına alınır.
